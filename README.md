## 🇬🇧 English

### ✨ Features
- 📖 **Library**: add titles from Comix.to using their URL
- 🔖 **Reading progress**: set your current chapter and browse available chapters
- ⏱️ **Release monitoring**: checks on launch, then every hour (manual check available)
- 🔔 **Notifications**: in-app updates + desktop notifications with cover, title and chapter
- 📁 **Organization**: sidebar folders, drag-and-drop card reordering
- 🧩 **Comix.to collections**: save collections and add titles to your library
- 🌍 **French / English** interface
- 🖥️ **Background mode**: lives in the Windows system tray
- 💾 **Local data**: your library stays on your PC

### 📥 Install
1. Go to the [**Releases page**](https://github.com/az6c/Manhwa-Veille/releases/tag/ManhwaVeille)
2. Download the `.exe` and run it
3. Open the app and add your first manhwa

> ⚠️ **Windows may show "Windows protected your PC"**: the app is not code-signed.
> Click **More info → Run anyway**.

## 🇫🇷 Français

### ✨ Fonctionnalités
- 📖 **Bibliothèque** : ajoute des titres depuis Comix.to avec leur URL
- 🔖 **Progression** : note ton chapitre actuel et consulte les chapitres disponibles
- ⏱️ **Surveillance** : vérification au lancement puis toutes les heures (manuelle possible)
- 🔔 **Notifications** : dans l'app + notifications de bureau avec cover, titre et chapitre
- 📁 **Organisation** : dossiers, réorganisation des fiches par glisser-déposer
- 🧩 **Collections Comix.to** : enregistre des collections et ajoute des titres
- 🌍 **Interface FR / EN**
- 🖥️ **Arrière-plan** : l'app reste dans la zone de notification Windows
- 💾 **Données en local** : ta bibliothèque reste sur ton PC

### 📥 Installation
1. Va sur la [**page des Releases**](https://github.com/az6c/Manhwa-Veille/releases/tag/ManhwaVeille)
2. Télécharge le `.exe` et lance-le
3. Ouvre l'app et ajoute ton premier manhwa

> ⚠️ **Windows peut afficher « Windows a protégé votre ordinateur »** : l'app n'est pas signée.
> Clique sur **Informations complémentaires → Exécuter quand même**.
